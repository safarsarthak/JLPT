# JLPT N5 Revision

A simple, interactive revision website designed to help Japanese learners practise JLPT N5 vocabulary, verb conjugations, and kanji.

## Features

- **Verb Flashcards:** Practise verbs from the Verbs 1–6 and Verbs 7–12 study sets.
- **Verb Conjugations:** Review dictionary, nai, ta, nakatta, and te forms.
- **Kanji Revision:** Learn N5 vocabulary with hiragana readings, English meanings, and individual kanji breakdowns.
- **Shuffle:** Randomise the order of flashcards.
- **Review Queue:** Mark difficult cards and revisit them after completing the original deck.
- **Progress Tracking:** Track your revision progress with a progress bar.
- **Previous and Next Navigation:** Move between cards at your own pace.
- **Responsive Sidebar:** Open and close the menu on desktop and mobile, with collapsible study-set lists.
- **Restart:** Start the current revision set again.

## Getting Started

1. Open the website using its published GitHub Pages link.
2. Select a study set: **Verbs 1–6**, **Verbs 7–12**, or **N5 Kanji with Words**.
3. Read the Japanese word or verb form displayed on the flashcard.
4. Try to recall its meaning before selecting **See Answer**.
5. Use **Next** and **Previous** to navigate through the cards.
6. Select **Review** to mark difficult cards for revision after completing the original set.
7. Use **Shuffle** to practise in a different order or **Restart** to begin again.

## Deployment

This project is a static website built with HTML, CSS, and JavaScript.

To deploy or update it using GitHub Pages:

1. Upload the website code to your GitHub repository.
2. Ensure the main HTML file is named `index.html`.
3. Open the repository's **Settings → Pages**.
4. Configure GitHub Pages to publish from the appropriate branch and folder.
5. Save the settings and open the published website.
